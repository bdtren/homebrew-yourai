# bdtren/homebrew-yourai

Homebrew tap for [yourai](https://yourai.bdtren.com), a CLI that builds and runs
your own local AI.

```sh
brew install --cask bdtren/yourai/yourai
yourai doctor
```

Update with `brew upgrade --cask yourai`, remove with `brew uninstall --cask yourai`.

The cask in `Casks/yourai.rb` is updated automatically for each release of
[bdtren/yourai-cli](https://github.com/bdtren/yourai-cli).
